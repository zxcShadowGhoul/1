# ДИП — прибыль

Простое PWA-приложение для учёта доходов по категориям и всех расходов с автоматическим подсчётом итога за месяц.

## Функции
- Доходы по категориям: кальяны, чай, напитки, снеки, прочее.
- Расходы: табак, уголь, закупки, аренда, зарплаты, коммунальные, налоги, ремонт, реклама, комиссии и прочее.
- Итог выбранного месяца: доходы минус расходы.
- История, фильтр, сводка расходов по категориям.
- Экспорт CSV и резервная копия JSON / восстановление.
- Сохранение в браузере на текущем устройстве.

## Обновить опубликованную версию на GitHub Pages
1. Распакуй архив на компьютере.
2. Открой папку репозитория `deep-house-app`.
3. Замени файлы из архива одноимёнными файлами (включая папку `icons`, `manifest.webmanifest` и `sw.js`).
4. Сохрани изменения и сделай Commit/Push через GitHub Desktop.
5. Подожди минуту, затем на iPhone закрой и снова открой приложение. Если показывается старая версия, перезагрузи страницу Safari; иногда нужно удалить веб-приложение с экрана «Домой» и добавить снова.

## Важно
Данные хранятся локально в браузере. Нет облачной синхронизации, учётных записей или разграничения прав. Экспортируй резервную копию регулярно. Это управленческий учёт, не бухгалтерская или налоговая отчётность.
